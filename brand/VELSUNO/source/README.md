# Reproducir
Dependencias Python: fonttools, reportlab, Pillow, PyMuPDF.
Desde una carpeta de trabajo vacía, ejecutar python /ruta/VELSUNO/source/rebuild.py.
Crea VELSUNO_REBUILD sin alterar el paquete original. Usa la fuente incluida; no requiere descargar archivos. Las aplicaciones UI son SVG/PNG, no código del SaaS.
El raster de exploración queda conservado, no se regenera ni es parte del logo final.
